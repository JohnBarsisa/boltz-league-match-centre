# Boltz League Match Centre

Open the [Season 6 match centre](https://johnbarsisa.github.io/boltz-league-match-centre/) and select **Ref Access** to sign in on the current page. A referee can select **Matches**, expand a fixture and choose **Edit lineup and timeline**.

The spectator view loads a bundled programme, then refreshes squads, fixtures and published match events from the hosted league service while the page is visible. The service checks referee permissions before accepting updates. GitHub Pages uses a tab-local session that ends on refresh. Passwords belong in the hosted service configuration.

GitHub Pages serves the repository root from `main`.
